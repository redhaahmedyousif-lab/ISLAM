# 📖 مراجعة التربية الإسلامية — الصف الثاني الإعدادي (الاختبار الأول)

موقع تفاعلي لمراجعة مادة التربية الإسلامية، يعمل مباشرة في المتصفح (افتح `index.html`).

## الأقسام
0. **⭐ أسئلة الامتحان المهمة** — الأسئلة العشرة المتوقعة
- **📖 المذكرة** — مذكرة المعلم كاملة + المذكرة العامة (ملخص منظّم لكل الدروس)
1. **القرآن الكريم** — سورة البقرة (163 - 164)
2. **الحديث الشريف** — فضل قراءة القرآن ومدارسته
3. **التفكر والتأمل في مخلوقات الله**
4. **صلاة الجنازة**
5. **فتح مكة (8 هـ)**

## أنواع الأسئلة
- اختيار من متعدد
- صح وخطأ (✓ / ✗) مع التصحيح
- أسئلة مقالية (كتابة نصية) مع تحقق من الكلمات الأساسية وإظهار الإجابة النموذجية
- أكمل الفراغ
- توصيل الكلمة بمعناها
- ترتيب تكبيرات صلاة الجنازة (سحب وإفلات أو أسهم)

يحفظ الموقع تقدمك تلقائياً، ويعرض نتيجتك في كل قسم وفي صفحة "النتيجة" مع قائمة بالأسئلة التي أخطأت فيها وإجاباتها الصحيحة.

## 💾 الحفظ التلقائي
- تُحفظ كل إجابة فوراً في المتصفح (`localStorage`) — حتى الإجابات التي لم يُتحقق منها بعد (نصوص، فراغات، توصيل، ترتيب).
- عند إغلاق الموقع أو تحديث الصفحة تُستعاد الإجابات ويعود الموقع إلى آخر قسم وآخر سؤال.
- زر «🗑 إعادة ضبط الاختبار / مسح الإجابات المحفوظة» لمسح كل شيء والبدء من جديد.
- الحفظ خاص بكل جهاز ومتصفح، ولا يعمل في وضع التصفح الخاص.
