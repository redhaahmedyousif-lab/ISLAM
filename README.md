# 📖 مراجعة التربية الإسلامية — الصف الثاني الإعدادي (الاختبار الأول)

موقع تفاعلي لمراجعة مادة التربية الإسلامية، يعمل مباشرة في المتصفح (افتح `index.html`).

## الأقسام
1. **القرآن الكريم** — سورة البقرة (163 - 164)
2. **الحديث الشريف** — فضل قراءة القرآن ومدارسته
3. **التفكر والتأمل في مخلوقات الله**
4. **صلاة الجنازة**
5. **فتح مكة (8 هـ)**

## أنواع الأسئلة
- اختيار من متعدد
- صح وخطأ (✓ / ✗) مع التصحيح
- أسئلة مقالية (كتابة نصية) مع تحقق من الكلمات الأساسية وإظهار الإجابة النموذجية
- أكمل الفراغ
- توصيل الكلمة بمعناها
- ترتيب تكبيرات صلاة الجنازة (سحب وإفلات أو أسهم)

يحفظ الموقع تقدمك تلقائياً، ويعرض نتيجتك في كل قسم وفي صفحة "النتيجة".

## التشغيل على GitHub Pages
من إعدادات المستودع: **Settings → Pages → Branch** واختر الفرع ثم `/ (root)`.
